Each HTML presentation includes its own styling, SVG artwork, JavaScript navigation, interactive project walkthroughs, and speaker notes. There are no external runtime dependencies or build steps. The PowerPoint companions also include speaker notes.

Use the arrow keys to navigate, **R** to switch between Read and Present modes, **N** to toggle speaker notes, **O** for the slide overview, **E** for the interactive walkthrough, **F** for full screen, **?** for keyboard help, and **Esc** to close a dialog.

To preview locally, run `python3 -m http.server 8000` from this directory, then visit `http://localhost:8000/`.

GitHub Pages serves the repository root from the `main` branch. `.nojekyll` keeps publication as a plain static site.
